# Фитокод — клиентский путь

[Открыть отчёт](https://davidishe.github.io/fitocode-qa-report/)

Тестирование от 25.10.2026; опубликовано 31.10.2026. 49 экранов со стрелками,
PDF на 22 страницах и 58 оригинальных PNG. Полный ZIP приложен к выпуску
`qa-2026-10-25`. Это публикация существующего среза, а не новый тест приложения.

Основной набор: 87 backend, 38 native core/integration, 9 основных UI успешно;
два native-теста явно пропущены. Дополнительный выбор обложки не прошёл:
`QR-PHOTO-QA-01`, причина не установлена, исправление не подтверждено.
Ручная проверка в том прогоне была недоступна из-за блокировки Mac.

Отдельный публичный репозиторий содержит только отчёт и тестовые снимки.
Исходников приложения, серверной конфигурации, рабочих данных и секретов нет.
Использованы синтетические аккаунты; QR-ссылки отозваны после их удаления.
Страница работает без JavaScript и внешних ресурсов; снимок открывается по
нажатию, переходы между разделами и список оригиналов используют обычный HTML.
PDF и PNG сохранены без изменения байтов; контрольные суммы в manifest.json.
